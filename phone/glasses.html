Camera / mic are blocked on this URL

You opened this page over plain http:// to a LAN address (e.g. 10.x.x.x). Chrome and Safari only expose navigator.mediaDevices on a secure context: https:// or http://localhost. That is why Connect shows got token then crashes — the token step works; camera access does not.

Fix (pick one):

  • Cloudflare Quick Tunnels (recommended, free) — install cloudflared (see Cloudflare install docs; Windows: winget install Cloudflare.cloudflared). Run two terminals while make phone and make backend are up: cloudflared tunnel --url http://localhost:8080 and cloudflared tunnel --url http://localhost:8000. Each prints a unique https://….trycloudflare.com URL — open the first + /glasses.html on your phone; paste the second into Backend URL.
  • USB + port forward — advanced; treat localhost on the phone as your PC via adb reverse.
Terminal A (with `make phone` running):
  cloudflared tunnel --url http://localhost:8080
→ phone: https://XXXX.trycloudflare.com/glasses.html

Terminal B (with `make backend` on :8000):
  cloudflared tunnel --url http://localhost:8000
→ Backend URL: https://YYYY.trycloudflare.com  (no trailing slash)
